# Craydoo Netherlands - Accounting

Defines a `cd.account.chart` ("Netherlands") whose account codes/names
mirror Odoo's `l10n_nl` module, so it can be applied onto a
`cd.account.ledger` via `craydoo_account`'s chart wizard.

The account codes and names in `data/cd.account.chart.account-nl.csv` are
taken from Odoo's `l10n_nl` module, originally authored by
[Onestein](https://www.onestein.eu). Credit to them for the original
chart of accounts data.
